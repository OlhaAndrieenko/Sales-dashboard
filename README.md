# Продаж товарів на території США (Sales_dashboard)
У  даному дашборді проаналізовано продажі товарів на території США, розподіл продажів за регіонами країни, штатами, роками та підкатегоріями товарів.
Дані для аналізу взяті з файлу sample_superstore.xsl.
# Інструменти:
- Excel
- Tableau.
  
Побудований дашборд має фільтри, що дозволяють фільтувати дані за певними критеріями (регіон, штат, рік, категорія товару).
